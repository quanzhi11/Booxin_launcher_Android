# Booxin 一键云服（白名单一期）

适用范围：联机账号白名单试用；远端空原版 dedicated。

## 谁能用

- 仅联机账号：`zrr`、`Booxin`
- 其它账号不显示「云服」Tab；接口返回 403

## 能开什么

| 项 | 值 |
|----|----|
| 版本 | `1.12.2`、`1.20.1`、`1.21.11`（原版） |
| 世界 | 仅空服，无存档上传/下载 |
| 坑位 | 全机最多 **2** 个实例 |
| 人数 | 每实例 `max-players=5` |
| 每账号 | 同时仅 1 个运行中实例 |
| TTL | 默认 4 小时；启动器约每 2 分钟心跳续期 |

## 启动器用法

1. 用白名单账号登录联机
2. 联机页 → **云服**
3. 选版本 → **一键开服** → 等待 Running
4. **进入云服**（`--quickPlayMultiplayer`）或把地址发给好友
5. 不用时点 **停服** 释放坑位（会删远端空世界目录）

坑位满时提示「云服坑位已满（2/2），请稍后再试」——本期**不做排队**。

## 控制面 API

默认基址候选（启动器探测）：

- `http://127.0.0.1:5015`
- `https://boonix.art/cloud`
- `http://175.178.174.103:5015`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/cloud-servers/capacity` | 坑位；Bearer 可选 |
| GET | `/api/cloud-servers/mine` | 我的实例 |
| POST | `/api/cloud-servers` | `{ "gameVersion", "name?" }` |
| GET | `/api/cloud-servers/{id}` | 状态 |
| POST | `/api/cloud-servers/{id}/stop` | 停服 |
| POST | `/api/cloud-servers/{id}/heartbeat` | 续期 |
| GET | `/api/health` | 健康检查 |

鉴权：`Authorization: Bearer <联机 JWT>`，服务端调 Auth `/api/auth/validate`。

错误码：`NOT_WHITELISTED`（403）、`SLOT_FULL`（409）、`VERSION_NOT_ALLOWED`（400）。
